ถ้าต้องการนับ “ทุก notify ของทุก user” เช่น key หลายตัว

notify:user:1
notify:user:2
notify:user:3

ใช้:

redis-cli --scan --pattern 'notify:user:*'

แล้วนับจำนวน key:

redis-cli --scan --pattern 'notify:user:*' | wc -l

แต่ถ้าต้องการ “รวมจำนวน message ทั้งหมดทุก queue”

เช่นแต่ละ key เป็น LIST

ใช้:

for k in $(redis-cli --scan --pattern 'notify:user:*'); do
  redis-cli LLEN "$k"
done | awk '{sum+=$1} END {print sum}'

ถ้ามี password:

for k in $(redis-cli -a 'PASSWORD' --scan --pattern 'notify:user:*'); do
  redis-cli -a 'PASSWORD' LLEN "$k"
done | awk '{sum+=$1} END {print sum}'

ถ้าใช้ key แบบ:

notify:user:mcap

ลองดู type ก่อน:

TYPE notify:user:mcap

จะได้:

list

หรือ:

string
ถ้าเป็น list notification

ดูทั้งหมด:

LRANGE notify:user:mcap 0 -1
ถ้าต้องการดูทุก key พร้อมค่า

ใช้ shell loop:

redis-cli --scan | while read key; do
  echo "=== $key ==="
  redis-cli TYPE "$key"
done

อันนี้ useful มากสำหรับ debug GPS notification

redis-cli MONITOR

LPUSH notify:user:mcap "{...}"
GET notify:user:mcap

ห้ามเปิดนานใน production
กิน CPU
ดู unread notification ของ user

ถ้าเก็บเป็น list:

LLEN notify:user:mcap

redis-cli --bigkeys

ดีมากสำหรับหา key ที่โตผิดปกติ


ถ้า key ของคุณเป็น list notification เช่น:

notify:user:mcap
notify:user:test
notify:user:admin

ต้องการดูทุก key พร้อมนับจำนวนข้อความในแต่ละ key ใช้แบบนี้ได้เลย:

redis-cli --scan --pattern 'notify:user:*' | while read key
do
  count=$(redis-cli LLEN "$key")
  echo "$key => $count"
done
